# AI 智能伴侣 · 账号体系接口契约（前端对接文档）

> 本文档是前端**登录 / 注册 / 找回密码**功能依赖的后端接口清单，供后端同学对照实现。
> 前端已全部就绪，后端实现以下接口后即可前后端联调。

---

## 一、统一约定

| 项目 | 约定 |
| --- | --- |
| 基础路径 | 前端统一走 `VITE_API_BASE_URL`（开发环境见 `.env.development`），接口路径为相对路径 |
| 响应结构 | 沿用现有 `{ code, message, data }`，**`code === 200` 表示成功**，其余为业务失败 |
| 鉴权方式 | **Token 鉴权**。登录/注册成功后端返回 `token`，前端存本地，后续所有请求头携带 `Authorization: Bearer <token>` |
| 失败场景 | 业务失败走 `code !== 200` + `message`；**未登录/令牌过期返回 HTTP 401**（前端据此跳回登录页） |
| 密码规则 | 6–20 位，**同时包含字母和数字**（前端已校验，建议后端同样校验） |

**前端存储键**（与后端无关，供了解）：`ai_companion_token`、`ai_companion_user`。

## 二、接口清单

### 1. 注册

- **POST** `/auth/register`
- 请求体：

```json
{
  "username": "xiaotiantian",
  "password": "Example123!",
  "question": "你最喜欢的城市是哪里？",
  "answer": "成都"
}
```

- 成功 `data`（**注册成功即自动登录**，返回 token 与用户信息）：

```json
{ "token": "xxx", "user": { "id": 1, "username": "xiaotiantian" } }
```

- 失败：`code !== 200`，`message` 如「该用户名已被注册」。

### 2. 登录

- **POST** `/auth/login`
- 请求体：

```json
{ "username": "xiaotiantian", "password": "Example123!" }
```

- 成功 `data`：

```json
{ "token": "xxx", "user": { "id": 1, "username": "xiaotiantian" } }
```

- 失败：`code !== 200`，`message` 如「用户名或密码错误」。

### 3. 找回密码 · 第一步：校验用户名并返回密保问题

- **POST** `/auth/question`
- 请求体：

```json
{ "username": "xiaotiantian" }
```

- 成功 `data`：

```json
{ "question": "你最喜欢的城市是哪里？" }
```

- 失败：`code !== 200`，`message` 如「该用户名不存在」。

### 4. 找回密码 · 第二步：校验密保答案

- **POST** `/auth/check-answer`
- 请求体：

```json
{ "username": "xiaotiantian", "answer": "成都" }
```

- 成功 `data`：`null`（`code === 200` 即校验通过）。
- 失败：`code !== 200`，`message` 如「密保答案错误」。

### 5. 找回密码 · 第三步：重置密码

- **POST** `/auth/reset-password`
- 请求体：

```json
{ "username": "xiaotiantian", "new_password": "NewExample123!" }
```

- 成功 `data`：`null`（`code === 200` 即重置成功）。
- 失败：`code !== 200`，`message` 说明原因。

### 6. 退出登录

- **POST** `/auth/logout`
- 需携带 `Authorization` 请求头。
- 成功 `data`：`null`。
- 说明：前端退出时**仅清除本地登录态**，此接口用于服务端失效 token（可选实现）。

## 三、密保问题枚举

前端「注册」页的密保问题下拉，`value` 即问题文本（与后端存储需一致）：

```
你最喜欢的城市是哪里？
你的第一只宠物叫什么名字？
你小学班主任的姓氏是？
你最喜欢的一部电影是？
你出生的城市是哪座？
```

## 四、前端调用示例（供后端理解数据流向）

登录成功后，前端将 `data.token` 存入 `localStorage`，后续每个请求由拦截器自动带上：

```text
Authorization: Bearer <token>
```

请求若返回 **HTTP 401**，前端会清除本地登录态并跳转 `/login`。

所有业务失败（`code !== 200`）由前端 `request.js` 拦截器统一 `alert` 展示 `message`，无需各页面重复处理。
