# 动态背景素材包（本地）

四个主题的动态背景素材**优先从 `login/` 子目录加载**（阿里云 OSS 直链已过期，仅作最后兜底保留在
`src/config/loginMedia.js`）。某一主题素材缺失或加载失败时，自动按以下顺序降级，
页面不会报错：

```
login/ 的视频 → login/ 的动图 → OSS 直链（loginMedia.js）→ 内置 CSS 渐变
```

## 视频放到哪个文件夹

**`public/materials/login/`** —— 把视频（和可选的动图）直接放进这个文件夹，文件名按下表命名即可。

## 文件命名（四主题）

| 文件名 | 用途 |
| --- | --- |
| `light.mp4`（或 `light.webm`） | 默认主题 · 背景视频 |
| `dawn.mp4`（或 `dawn.webm`） | 黎明主题 · 背景视频 |
| `dark.mp4`（或 `dark.webm`） | 黑夜主题 · 背景视频 |
| `wuxia.mp4`（或 `wuxia.webm`） | 国风武侠主题 · 背景视频（同时用于「入梦江湖」过场） |
| `light.gif` / `dawn.gif` / `dark.gif` / `wuxia.gif`（也支持 webp / apng） | 对应主题的动图兜底（可选，视频缺失/失败时显示） |

- **四个视频放进来即可生效**；同一主题视频和动图都放的话，视频优先。
- 扩展名与上表不同（如 `light.webm`）：改 `src/config/loginMedia.js` 里对应主题的
  `local` 字段即可（动图改 `localImage` 字段）。
- 暂时没有的主题直接不放，该主题自动退到下一级兜底。

## 生效方式

- **开发模式**（`npm run dev`）：文件放入本目录后刷新页面即生效，无需重启。
- **生产部署**：`public/` 下的文件在构建时拷贝进 `dist/`，所以新增/替换素材后需要
  重新构建（`npm run build`）；也可以直接把文件放进已部署目录的 `materials/login/` 下，
  免构建热替换。

## 素材建议

- **视频**：MP4（H.264）或 WebM，1920×1080 左右，单个 ≤ 8MB（越小加载越快），
  无需音轨（页面强制静音循环播放）。
- **动图**：GIF / WebP / APNG 均可，注意 WebP 和 APNG 需要是**动图**格式。
- **色调**：默认主题建议粉彩色调；黎明主题建议暖霞、金橙、朝霞色调；黑夜主题建议
  暗紫、暗红、深夜蓝调；国风主题建议朱砂红、鎏金武侠色调 —— 页面遮罩与文字配色
  会与这四组色调保持一致。

## fonts/ 字体目录

| 文件 | 用途 |
| --- | --- |
| `fonts/MaShanZheng-Regular.ttf` | 国风限定主题书法字体（马善政楷书，自托管约 5.6MB） |

国风主题的标题、下拉选项与「入梦江湖」过场大字均使用该字体；删除或加载失败时自动
回落系统楷体（STKaiti/KaiTi），页面不会出错。
